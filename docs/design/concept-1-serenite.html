Moi

Pourquoi ça marche

  • Registre visuel « soin » : rassure les parents, crédible pour une tutelle.
  • Une seule couleur d'accent → les alertes ambre/rouge ressortent vraiment.
  • Reprend vos tokens existants (Inter, radius, échelle d'espacement) : migration rapide depuis l'admin-web actuel.
  • Contraste élevé sur fond clair : lisible sur tablette bon marché en salle.

À surveiller

  • Densité faible : un directeur multi-sites devra scroller davantage.
  • Style très répandu en 2026 — peu différenciant face à Brightwheel/Famly.
  • Fond clair = fatigue visuelle pour le veilleur de nuit / usage prolongé.

Coût d'implémentation

  • Faible. Palette + rayons + ombres à changer dans tokens.ts.
  • Aucune restructuration de composant côté React.
  • Flutter : ThemeData + Material 3, direct.
  • RTL arabe : symétrique, aucun blocage.
